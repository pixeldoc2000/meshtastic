## User/Program Button GPIO

For the Lora V2.1-1.8, GPIO IO12 for example can be pulled to ground to act as a user button. It will progress through the screen pages and/or wake up the device. A simple push switch can be added for this purpose.

<b>NOTE:</b> The GPIO needs to be configured in recent Firmware Versions. See: https://meshtastic.org/docs/configuration/radio/device/#gpio-for-user-button
